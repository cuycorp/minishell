## ✅ Goal

1. **Use `stdout_fd`**:

   * If output needs redirection (e.g. `> file.txt`), it should be done via `ctx->stdout_fd`.
   * This means you don’t need to do `open()`/`dup2()` inside redirection logic anymore.

2. **Use `should_fork`**:

   * Let the centralized `exec_context` decide whether to fork.
   * This keeps execution behavior consistent across parent-builtins, subshells, and pipelines.

## ✅ Redirection Handling Changes

Instead of applying redirections directly with `dup2()` inside `ft_setup_redirection()`, you now let `ft_setup_redirection()`:

* **open the necessary input/output fds**
* but **don’t call `dup2()`**
* just **update `ctx->stdin_fd` and `ctx->stdout_fd`**

---

### 🔁 Modify `ft_setup_redirection()` to update `ctx`

```c
bool	ft_setup_redirection(t_redirection *redirection, t_exec_context *ctx)
{
	t_redirection	*last_input = ft_get_last_input_redirection(redirection);
	int				fd;

	while (redirection)
	{
		if (redirection->type == HEREDOC || redirection->type == REDIRECT_IN)
		{
			fd = ft_handle_inputs(...);
			if (fd == -1)
				return false;
			if (redirection == last_input)
				ctx->stdin_fd = fd;
			else
				close(fd);
		}
		else if (redirection->type == REDIRECT_OUT)
		{
			fd = open(redirection->target, O_WRONLY | O_CREAT | O_TRUNC, 0644);
			if (fd < 0)
				return (perror("open"), false);
			ctx->stdout_fd = fd;
		}
		else if (redirection->type == APPEND_OUT)
		{
			fd = open(redirection->target, O_WRONLY | O_CREAT | O_APPEND, 0644);
			if (fd < 0)
				return (perror("open"), false);
			ctx->stdout_fd = fd;
		}
		redirection = redirection->next;
	}
	return true;
}
```

## ✅ Updated `ft_exec_simple_command`

### 🎯 Full version with `ctx->should_fork` and `ctx->stdout_fd`:

```c
int	ft_exec_simple_command(t_command *command, t_shell *data,
		t_exec_context *ctx, int *last_pid)
{
	pid_t	pid;
	int		exit_code;

	if (!command || !data || !ctx || !last_pid)
		return (EXIT_FAILURE);

	// Redirection setup updates ctx->stdin_fd and ctx->stdout_fd
	if (!ft_setup_redirection(command->redirection, ctx))
		return (EXIT_FAILURE);

	bool is_parent_builtin = ft_is_parent_builtin(command->name);
	bool run_in_parent = is_parent_builtin && !ctx->is_in_pipeline;

	if (!ctx->should_fork || run_in_parent)
	{
		// Apply redirection in parent
		if (ctx->stdin_fd != STDIN_FILENO)
		{
			dup2(ctx->stdin_fd, STDIN_FILENO);
			close(ctx->stdin_fd);
		}
		if (ctx->stdout_fd != STDOUT_FILENO)
		{
			dup2(ctx->stdout_fd, STDOUT_FILENO);
			close(ctx->stdout_fd);
		}
		exit_code = ft_exec_parent_builtin(command, data);
		*last_pid = -1;
		return exit_code;
	}

	// === FORK ===
	pid = fork();
	if (pid < 0)
		return (perror("fork failed"), EXIT_FAILURE);
	if (pid == 0)
	{
		// CHILD
		if (ctx->stdin_fd != STDIN_FILENO)
			dup2(ctx->stdin_fd, STDIN_FILENO);
		if (ctx->stdout_fd != STDOUT_FILENO)
			dup2(ctx->stdout_fd, STDOUT_FILENO);

		if (ctx->stdin_fd != STDIN_FILENO)
			close(ctx->stdin_fd);
		if (ctx->stdout_fd != STDOUT_FILENO)
			close(ctx->stdout_fd);

		if (ft_is_builtins(command->name))
			exit(ft_exec_builtin(command, data));
		else
			exit(ft_exec_command(command, data));
	}

	// PARENT
	if (ctx->stdin_fd != STDIN_FILENO)
		close(ctx->stdin_fd);
	if (ctx->stdout_fd != STDOUT_FILENO)
		close(ctx->stdout_fd);

	if (data->pid_count < data->command_count)
	{
		data->pids[data->pid_count++] = pid;
		*last_pid = pid;
	}
	return EXIT_SUCCESS;
}
```
