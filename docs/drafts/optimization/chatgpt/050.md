## ✅ 4. New: `ft_spawn_heredoc_process`

```c
bool ft_spawn_heredoc_process(t_redirection *redir, t_exec_context *ctx)
{
	int pipe_fd[2];
	pid_t pid;

	if (pipe(pipe_fd) == -1)
		return (perror("pipe"), false);

	pid = fork();
	if (pid < 0)
		return (perror("fork"), false);

	if (pid == 0)
	{
		// Child
		close(pipe_fd[0]);
		ft_run_heredoc_child(redir, pipe_fd[1], ctx);
		// Should not return
		exit(EXIT_FAILURE);
	}

	// Parent
	close(pipe_fd[1]);
	redir->heredoc_fd = pipe_fd[0];

	if (ctx->shell && ctx->shell->pids)
		ctx->shell->pids[ctx->shell->pid_count++] = pid;

	return true;
}
```

## ✅ 5. Refactored: `ft_run_heredoc_child`

This version handles:

* `readline()` from the user
* Writing to pipe
* Stops when delimiter is matched
* Supports debug output

```c
void ft_run_heredoc_child(t_redirection *redir, int write_fd, t_exec_context *ctx)
{
	char *line;
	size_t delim_len = ft_strlen(redir->target);

	while (1)
	{
		line = readline("> ");
		if (!line)
			break;

		if (ft_strncmp(line, redir->target, delim_len) == 0 && line[delim_len] == '\0')
		{
			free(line);
			break;
		}

		write(write_fd, line, ft_strlen(line));
		write(write_fd, "\n", 1);
		free(line);
	}

	close(write_fd);

	if (ctx->enable_debug)
		fprintf(stderr, "[DEBUG] Heredoc '%s' complete\n", redir->target);

	exit(EXIT_SUCCESS);
}
```

* You should `waitpid()` on all `shell->pids` before continuing execution to ensure heredoc processes terminate properly.
