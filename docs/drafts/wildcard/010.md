## ✅ Part 2: Optimized Iterative Version

Here’s a correct and efficient **iterative** implementation that supports `*` wildcards and doesn’t require recursion.

```c
bool	ft_match_pattern(char *pattern, char *filename)
{
	int i = 0; // index in pattern
	int j = 0; // index in filename
	int star_idx = -1;
	int match = 0;

	if (!pattern || !filename)
		return false;

	while (filename[j])
	{
		if (pattern[i] == filename[j] || pattern[i] == '?')
		{
			i++;
			j++;
		}
		else if (pattern[i] == WILDCARD_CHARACTER)
		{
			star_idx = i;
			match = j;
			i++;
		}
		else if (star_idx != -1)
		{
			// Backtrack: try to match more chars with *
			i = star_idx + 1;
			match++;
			j = match;
		}
		else
		{
			return false;
		}
	}

	// Consume remaining stars in pattern
	while (pattern[i] == WILDCARD_CHARACTER)
		i++;

	return pattern[i] == '\0';
}
```
